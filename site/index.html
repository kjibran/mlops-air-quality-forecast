How it works

The forecast describes the air at one roadside monitoring station on Jagtvej, not the whole street. Every part runs on its own, on free infrastructure, and nothing on this page is updated by hand.

  1. 1Measure

    Hourly NO₂ from official monitoring stations and weather data are collected into a Postgres database every hour.

  2. 2Freeze

    Each week the data is saved as a versioned snapshot, so every model can be traced to the exact data it learned from.

  3. 3Retrain

    A new model is trained every week. It replaces the current one only if it is at least 2% more accurate on the same recent weeks.

  4. 4Forecast

    Every hour, the current model predicts the next 24 hours from the latest measurements and the weather forecast.

  5. 5Check

    Daily checks watch data freshness and live accuracy, and a weekly report flags unusual inputs.
